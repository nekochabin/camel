# 導入初週アクションリスト

> 目標: 最小構成で運用をスタートし、無理なく習慣化する。
> 3日間で基盤を整え、残り4日で実際に使いながら感覚をつかむ。

> **パスの読み替えについて**
> このファイル内の `~/camel/` は、リポジトリの実際の場所に置き換えて読んでください。
> 確認方法: `pwd` をリポジトリ内で実行するか、以下で変数にセットしておくと便利です。
> ```bash
> export CAMEL_DIR="/home/user/camel"   # ← 自分の環境に合わせて変更
> echo $CAMEL_DIR  # 確認
> ```
> 以降のコマンドは `~/camel/` の代わりに `$CAMEL_DIR/` で動きます。

## Day 1（基盤構築）

### やること
- [ ] **CLAUDE.md を配置する**
  ```bash
  # リポジトリルートに配置済みであることを確認
  ls -la ~/camel/CLAUDE.md
  ```

- [ ] **Hooksスクリプトをホームディレクトリにコピーする**
  ```bash
  mkdir -p ~/.claude/hooks ~/.claude/logs ~/.claude/templates
  cp $CAMEL_DIR/.claude/hooks/*.sh ~/.claude/hooks/
  chmod +x ~/.claude/hooks/*.sh
  ```

- [ ] **settings.json を配置する**
  ```bash
  cp $CAMEL_DIR/.claude/settings.json ~/.claude/settings.json
  ```

- [ ] **動作確認: 通知Hookをテスト**
  ```bash
  bash ~/.claude/hooks/notify_on_wait.sh
  # → 通知またはベル音が鳴ることを確認
  ```

- [ ] **動作確認: 危険コマンドHookをテスト**
  ```bash
  bash ~/.claude/hooks/check_dangerous_command.sh "rm -rf /"
  # → 警告メッセージが出て終了コード2が返ることを確認
  echo "終了コード: $?"
  ```

### 確認ポイント
- Claudeを起動したとき、CLAUDE.mdのルールが参照されているか
- セッション終了後に `~/.claude/logs/` にログが作られているか
  ```bash
  ls ~/.claude/logs/          # ログファイルの存在確認
  cat ~/.claude/logs/$(date +%Y-%m-%d).md  # 今日のログを確認
  ```

## Day 2（探索・計画フェーズの練習）

### やること
- [ ] **実際のタスク1件を「探索→計画」だけで動かしてみる**
  - 編集はしない
  - `daily_checkin.md` テンプレートを使ってセッションを開始する
  - 探索フェーズプロンプトをそのまま使う

- [ ] **感じた違和感・気づきをメモする**
  - CLAUDE.mdに追記すべきルールがあれば書き留める
  - プロンプトの修正案があればメモ

- [ ] **テンプレートをコピーしてローカルに保存**
  ```bash
  cp $CAMEL_DIR/.claude/templates/*.md ~/.claude/templates/
  ```

### 確認ポイント
- 「まだ編集しない」指示がClaudeに守られているか
- 出力の要約形式（実施内容・確認方法・次ステップ）が出ているか

## 初週の「やらないこと」

- Hookをすべて完璧に動かそうとしない（通知と危険コマンド検出の2つで十分）
- CLAUDE.mdを完璧にしようとしない（使いながら育てる）
- サブエージェントの導入（Phase 4まで保留）
- 自動テストHookの導入（Phase 3まで保留）
