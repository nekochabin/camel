# 週次レビュー テンプレート

> 使い方: 毎週末（金曜か日曜）にClaudeとの振り返りセッションで使う

---

## 週次振り返りプロンプト

```
今週の作業ログ（~/.claude/logs/）を読んで、
以下の観点で週次レビューをしてください。

1. 【完了確認】今週完了したタスクの一覧
2. 【継続確認】持ち越しになっているタスクと理由
3. 【テンプレ化候補】繰り返し発生したタスク・パターン
4. 【改善点】ワークフローで無駄・手戻りがあった点
5. 【来週の優先順位】高/中/低で3つずつ候補を挙げる

出力は箇条書きで簡潔にまとめてください。
```

---

## 週次メンテナンスチェックリスト

### CLAUDE.md の見直し
- [ ] 今週追加したい運用ルールがあるか確認
- [ ] 古くなったルールを削除または更新
- [ ] ワークフロープロンプトが実態に合っているか確認

### テンプレートの整理
- [ ] 新しく作ったテンプレートを `.claude/templates/` に保存
- [ ] 使わなくなったテンプレートを整理

### Hooksの確認
- [ ] 各Hookが期待通り動いているか確認
- [ ] エラーログがないか確認

### プロンプト資産の棚卸し
- [ ] 良かったプロンプトを記録したか
- [ ] 次週使いまわせるテンプレートに昇格するか判断
