# 日次チェックイン テンプレート

> 使い方: セッション開始時にこのテンプレートをコピーし、空欄を埋めてClaudeに渡す

---

## 今日の作業開始チェックイン

**日付**: YYYY-MM-DD
**優先タスク**: （1〜2行で）

### 前回の続きから再開する場合
```
前回のログ: ~/.claude/logs/YYYY-MM-DD.md を読んで、
作業の文脈を把握してください。まだ何も変更しないでください。
```

### 新しいタスクを始める場合
```
【探索】
以下のタスクに取り掛かる前に、関連ファイル・フォルダを探索して
構造と注意点を整理してください。まだ編集はしないでください。

タスク: ＿＿＿＿＿＿＿＿＿＿
```

---

## 今日の終了チェックアウト

### 振り返りプロンプト
```
今日の作業を以下の観点で振り返ってください:
1. 完了したこと
2. 途中で止まっていること（次回の再開ポイント）
3. 気になった点・改善できそうな点
4. 明日やること（候補）
```

### ログ確認
- [ ] `~/.claude/logs/YYYY-MM-DD.md` に自動追記されているか確認
- [ ] 次回再開メモを手動で書き込む
