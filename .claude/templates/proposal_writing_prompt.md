# 提案書作成 プロンプトテンプレート

> 用途: 提案書の骨子・アウトライン・各セクションの中身をClaudeと一緒に作る
> 使い方: `< >` の部分を自分の状況に合わせて書き換えてから使う

---

## 探索フェーズ（提案の前提整理）

```
以下の提案について、書き始める前に前提を整理してください。

【提案テーマ】<例: 社内生成AI活用推進の提案>
【提案先】<例: 経営層 / 事業部長 / 人事部門>
【背景・課題】<例: 業務効率化が急務だが、AIツールの活用が進んでいない>
【提案者の立場】<例: 人材育成担当者>
【制約条件】<例: 予算上限100万円、3ヶ月以内に着手>

整理してほしい観点:
1. 提案先が最も重視しそうな判断軸（コスト・リスク・効果・実現性など）
2. この提案が通るための「成功条件」の候補
3. 想定される反論・懸念点
4. 提案書に必要なセクションの候補

まだ提案書の中身は作らないでください。
```

---

## 計画フェーズ（構成案の作成）

```
以下の条件で提案書の構成案を作成してください。

【提案テーマ】<　>
【提案先】<　>
【分量の目安】<例: A4で3枚以内 / スライド10枚程度>

各セクションについて以下を明記してください:
- セクション名
- そのセクションで伝えること（1〜2行）
- 提案先が「なぜこれが必要か」を理解するうえでの役割

まだ各セクションの中身は書かないでください。
```

---

## 実行フェーズ（セクション別の中身作成）

```
提案書の「<セクション名>」だけを書いてください。
以下を含めてください:
- 主張（このセクションで言いたいこと）
- 根拠・データ・事例（あれば）
- 提案先の懸念を先回りした一言

書き終えたら、変更点・次に書くべきセクション候補を要約してください。
```

---

## レビューフェーズ（提案書全体の評価）

```
以下の観点で提案書全体をレビューしてください:

1. 【目的適合】提案先の判断軸に応えているか
2. 【論理構造】主張→根拠→結論の流れが通っているか
3. 【抜け漏れ】想定される反論に答えられていない箇所はないか
4. 【削れる箇所】冗長または不要なセクション・表現はないか
5. 【次の改善】優先度の高い修正点を2〜3点に絞って提示する
```

## 提案書の典型的な構成（参考）

```
1. エグゼクティブサマリー（結論を1ページで）
2. 現状と課題（なぜ今やるべきか）
3. 提案内容（何をするか）
4. 期待効果（やるとどうなるか）
5. 実施計画（いつ・誰が・どうやるか）
6. コスト・リソース（いくらかかるか）
7. リスクと対策（懸念点への回答）
8. 承認事項（何を決めてほしいか）
```
